# Core.xyz — Community Music Tracks

Place `.mp3` audio files in this `music/` directory for the **Core.xyz** in-game Music Player.

## How to Add Tracks
1. Upload `.mp3` files into this `music/` folder (keep filenames clean without spaces, e.g., `track1.mp3`, `night_drive.mp3`).
2. Raw URL format used by the script:
   `https://raw.githubusercontent.com/FeykHere/Tester/main/music/<filename>.mp3`
3. All tracks are automatically downloaded and cached locally into `CoreXyz_Music/` via `getcustomasset` for instant playback.
